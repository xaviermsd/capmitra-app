# CapMitra brand kit

Brand name: **CapMitra**. The **EDIT** badge is a sub-label: use it in logos, but say and write "CapMitra" in text.
Store title: **CapMitra: Captions & Video Editor**. Tagline: **Captions. Audio. Video Editing.**

All text in these files is converted to outlines, so they look the same on every computer without the font installed.

## Colours
| Name | Hex | Use |
|---|---|---|
| Electric Lime | `#D6FF36` | Icon background, EDIT badge, highlights. Fill only, never lime text on white |
| Ink Black | `#080808` | Wordmark, outlines, hard shadows |
| Warm White | `#F7F8F4` | Light backgrounds |
| Slate Grey | `#58616F` | Tagline on light (use `#A3A9B5` on dark) |

## Typography: Plus Jakarta Sans (free, Google Fonts)
| Element | Weight | Details |
|---|---|---|
| "CapMitra" wordmark | ExtraBold 800 | letter spacing -2% |
| "EDIT" badge | Bold 700 | ALL CAPS, letter spacing +8% |
| Tagline | Medium 500 | sentence case |

## Which file to use
| Need | File |
|---|---|
| App icon / app stores | `png/capmitra-icon-1024.png` (rounded) or `png/capmitra-icon-square-1024.png` (stores add their own corners) |
| Android / PWA icons | `png/capmitra-icon-maskable-512.png`, `-192.png` |
| iPhone home screen | `png/capmitra-icon-square-180.png` |
| Browser tab | `png/favicon.ico` (16/32/48, simplified icon) |
| Website header (light) | `svg/capmitra-logo-horizontal-transparent-ink.svg` |
| Website header (dark) | `svg/capmitra-logo-horizontal-transparent-white.svg` |
| Logo on a card / slide | `svg/capmitra-logo-horizontal-light.svg` / `-dark.svg` |
| Wordmark only | `svg/capmitra-wordmark-ink.svg` / `-white.svg` (with EDIT), `-nobadge-` versions without |
| Video watermark | `svg/capmitra-watermark.svg` / `png/capmitra-watermark@2x.png` |
| Link previews (WhatsApp, Instagram, X) | `png/capmitra-social-1200x630.jpg` |
| Alternative icon (black tile) | `svg/capmitra-icon-dark.svg` |

## Rules
- Below 48px use the **small** icon (`capmitra-icon-small`): no ring or shadow, so it stays readable.
- Keep clear space around the logo of at least the height of the "C".
- Don't recolour, stretch, add gradients or effects, or put lime text on white.
- The EDIT badge can be removed later: use the `-nobadge-` files.
